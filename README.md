# hyperframe

Generatore di caroselli immagine (4 slide, 1080×1350) per i post Instagram/Facebook degli immobili — stesso stile grafico del Kit Acquisizione (Playfair Display + Inter, navy/oro).

Apri `index.html` nel browser, compila i dati dell'immobile, carica le due foto e scarica lo ZIP con le 4 slide pronte da pubblicare come carosello:

1. Copertina (foto + prezzo + indirizzo)
2. Caratteristiche (foto + m²/locali/piano/zona)
3. Punti di forza (elenco editabile)
4. Contatto (agenzia + agente + CTA)

Nessun server richiesto: funziona interamente lato client, pronto anche per GitHub Pages.
